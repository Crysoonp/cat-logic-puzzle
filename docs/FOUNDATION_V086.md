# ねこみちロジック 基盤 Ver.0.8.6

## 変更内容
- `game-state.js` を新設し、状態の初期生成をゲーム本体から分離した。
- 状態を進行、盤面、実行時の3境界へ分類した。
- 中断盤面の保存用スナップショット生成を共通化した。
- 既存セーブ形式、操作、画面表示は変更していない。

## 状態境界
- 進行状態: ハート、カリカリ、クリア履歴、ボス進行。
- 盤面状態: 現在ステージ、得点、ミス、ヒント、猫、印、入力モード。
- 実行時状態: タイマー、ドラッグ、ログ、画面内一時状態。

## 次工程
中断盤面の復元処理を状態基盤へ段階的に移し、入力値検証を強化する。
