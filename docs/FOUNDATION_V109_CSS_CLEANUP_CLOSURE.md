# ねこみちロジック CSS整理工程クローズ Ver.0.8.29

## 結論
2回目のCSS削除は行わない。Ver.0.8.26で削除した8個の未使用セレクターを、今回の整理工程の唯一の削除成果として維持する。

## 理由
今回の簡易カスケード監査は、`100%`、`50%`、`to`などのキーフレーム内部を通常セレクターとして誤認した。また、`rgba()`等の関数値も分割され、`255`や`inset 0 1px 1px rgba(255`などの偽候補を生成した。

実在する残りの重複は、レスポンシブ上書き、後勝ち調整、動的表示、金枠・履歴・MARK・特殊演出などに関係する。現在の証拠では安全な完全一致重複を確定できない。

## 固定方針
- `style.css`はVer.0.8.26のハッシュを維持する。
- 2回目の整理候補は未選定とする。
- 今後CSS整理を再開する場合は、CSS構文を正しく扱える標準準拠パーサーと整理されたGit基準点を先に用意する。
- CSS整理と他の機能追加を同じ更新で混在させない。
